# Security Policy

## Scope

MetaCompletionTracker runs entirely inside World of Warcraft's sandboxed client Lua environment and does not make network requests or execute external binaries.

## Reporting a Vulnerability

If you discover a security concern affecting the repository, release artifacts, or GitHub Actions workflows:

1. **Do not** open a public issue with sensitive details.
2. Report the finding privately via [GitHub Security Advisories](https://github.com/karan-banwasi/MCT/security/advisories/new).
3. Include a clear description and reproduction steps so it can be reviewed promptly.
